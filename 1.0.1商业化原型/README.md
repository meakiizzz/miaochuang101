# 妙创 1.0.1 商业化独立原型

通过本地 HTTP 服务打开 `index.html`（当前预览地址 http://127.0.0.1:8871/）。

本目录独立于 `原型/全页面` 的 1.0.0 原型。所有支付、短信、生成和保存反馈均为本地演示，不调用真实服务。

## 体验方式

- 左侧 8 个场景会重置演示身份和样例内容；右侧记录每步判断结果。
- 演示购买：在模拟内购弹窗选择成功、取消或失败。
- 手机绑定：任意以 1 开头的 11 位号码，验证码 `246810`。
- 图片上传：点击上传区域调用浏览器 / 系统的文件选择器，仅接收 JPG / PNG，最大 10 MB；无自定义相册，无拍照入口。
- 新任务在「我的」卡片上显示生成状态，约 8 秒后完成。左侧可模拟提交失败（不扣豆）或生成失败（按原来源退豆）。
- 演示控制可模拟绑定冲突、会员到期、周续费、会员退款和妙豆包退款。
- 刷新页面会重置本地演示；不会读取或改写 1.0.0 的用户状态。

## 已包含的页面与流程

创作、灵感、模板详情、普通创作页、模板传图、AI 帮写抽屉、一句话海报、我的作品、生成成功 / 失败、设置、订阅、手机绑定、妙豆充值、妙豆明细、用量表、模拟内购和恢复购买。

- 拦截顺序：会员 → 手机绑定 → 对应操作 → 生成时检查妙豆。
- 会员购买成功先发赠豆，绑定后自动继续原操作。
- 购买后的绑定页展示「会员已开通」，支持左上角返回。返回保留已购权益和原编辑内容；再次进行受限操作时继续要求绑定。
- 妙豆包购买成功返回原页，用户手动再次生成。
- AI 帮写自动生成，重新生成 / 采用，不额外扣豆，无补充要求输入框。
- 生成提交成功先扣豆，立即进入「我的」，系统失败按原来源退回。
- 妙豆优先使用赠送部分；旧周期已清零的赠豆不因失败退回而延长。
- 到期后保留充值妙豆与历史作品；已提交任务继续执行。

## 尚未定稿的内容

图片和视频的单次生成用量暂统一为 400 妙豆，AI 帮写不额外扣豆。充值档位和价格已配置。

充值妙豆有效期、账号权益合并、交易到账补查、任务超时和退款已消耗部分等仍依照需求记录待后续确定。本原型不代替正式的内购、计费或服务端账本实现。
